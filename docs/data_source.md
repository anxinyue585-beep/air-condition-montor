# 数据来源说明

## 数据集名称

城市空气质量小时级实验数据集

## 来源构成

1. 项目原始种子数据：`src/api/dataset.json`
   - 覆盖城市：北京、上海、广州、深圳、成都、杭州。
   - 字段：AQI、PM2.5、PM10、SO2、NO2、空气质量等级、近期 PM2.5 波动。
   - 用途：作为项目前端展示和数据生成的基础样本。

2. 公开数据结构参考：UCI Machine Learning Repository 的 Beijing Multi-Site Air-Quality Data
   - 网址：https://archive.ics.uci.edu/dataset/501/beijing+multi+site+air+quality+data
   - 该数据集包含多监测站、逐小时空气质量记录，适合作为空气质量大数据项目的数据字段和清洗流程参考。

3. 指标标准参考：环境空气质量指数 AQI 技术规定 HJ 633-2012
   - 发布单位：生态环境相关标准体系。
   - 用途：用于 AQI 等级划分、污染物字段解释和数据合理范围控制。

## 数据生成口径

课程实验环境中，完整数据由 `scripts/build_air_quality_dataset.py` 可复现生成。生成数据保留真实空气质量数据常见的结构特征：

- 时间粒度：小时级。
- 空间粒度：城市 + 监测点。
- 覆盖范围：60 个城市、120 个监测点、2025-01-01 至 2025-12-31。
- 主要字段：AQI、PM2.5、PM10、SO2、NO2、CO、O3、温度、湿度、风速。
- 数据规模：1,051,200 条清洗后记录，满足课程建议的 CSV 100 万条以上要求。

## 说明

本数据集定位为课程大作业实验数据集，不作为真实环境监测结论使用。后续如需要替换成真实下载数据，可将外部原始 CSV 放入 `data/raw/`，沿用当前字段字典和清洗流程。
